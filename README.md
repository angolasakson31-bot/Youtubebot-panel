# YouTubeBot Kontrol Paneli

Telefondan açılan kontrol paneli. Veriler özel `YouTubeBot` deposunda durur;
bu sayfa onlara senin GitHub erişim anahtarınla (token) ulaşır. Token sadece
kendi tarayıcında saklanır, bu depoda hiçbir gizli bilgi yoktur.

Kaynak: `YouTubeBot/panel/index.html` (değişiklikler orada yapılır, buraya kopyalanır).
